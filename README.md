About the project

This is my personal portfolio website created for IWaMAD SIS Assignment 1. It introduces me, shows my web development practice projects, and provides a contact form. I built the website using HTML5, CSS3, and vanilla JavaScript without any frameworks.

Design decisions

1. Colours: I chose beige, brown, and terracotta because they create a warm and simple visual style.
2. Layout: I used a single-column layout on mobile and a three-column projects grid on desktop to make the website easier to use on different screens.
3. Accessibility:I added labels to form fields, visible keyboard focus styles, and a dark mode toggle to improve the user experience.

Features

- About Me, Projects, and Contact sections
- Responsive layout for mobile and desktop
- Light and dark themes
- Contact form with custom validation messages
- Semantic HTML and keyboard focus styles
